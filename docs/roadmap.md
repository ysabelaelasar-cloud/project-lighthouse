# Lighthouse Roadmap

## Phase 0 — Foundation

- Historical data analysis
- Pattern discovery
- Product design
- Architecture

Status: In Progress

## Phase 1 — Beacon

Goal:

Centralize all personal health information into one dashboard.

Features:

- Dashboard
- Timeline
- Historical trends
- Data imports

---

## Phase 2 — Compass

Goal:

Generate personalized recommendations.

Examples:

- Suggested pacing
- Daily capacity
- Recovery guidance

---

## Phase 3 — Horizon

Goal:

Predict outcomes.

Examples:

"What happens if I grocery shop today?"

---

## Phase 4 — Harbor

Goal:

Automated data synchronization and real-time decision support.
